# 🌾 Agrisense AI Platform

An AI-powered smart agriculture platform that recommends the best crops based on soil nutrients and weather conditions.

---

## 🚀 Features

* 🌱 Crop recommendation using Machine Learning
* 📊 Top 3 crop predictions with confidence scores
* 📈 Visual bar chart for comparison
* 🌦 Soil + weather input system
* 📘 Crop details (season, soil type, tips)
* 🎨 Interactive UI built with Streamlit

---

## 🧠 How It Works

1. User inputs:

   * Soil nutrients (Nitrogen, Phosphorus, Potassium)
   * Weather data (Temperature, Humidity, pH, Rainfall)

2. Machine Learning model processes the input

3. App predicts:

   * Best crop recommendation
   * Top 3 crops with confidence %
   * Additional crop details

## ▶️ How to Run Locally

1. Clone the repository:
   git clone https://github.com/zoyashaikh23/Agrisense-ai.git

2. Navigate into the folder:
   cd Agrisense-ai

3. Install dependencies:
   pip install -r requirements.txt

4. Run the app:
   streamlit run app.py
