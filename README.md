# 🌾 Agrisense AI Platform

An AI-powered smart agriculture platform that recommends the best crops based on soil and weather conditions.

---

## 🚀 Features

- 🌱 Crop recommendation using Machine Learning
- 📊 Top 3 crop predictions with confidence
- 📈 Visualization using charts
- 🌦 Soil + weather input system
- 📘 Crop details (season, soil type, tips)

---

## 🧠 Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
